# 职业顾问（ai-interviewer）

一个基于 AI 对话的双通道求职辅助 Skill：通过模拟面试准备具体岗位，通过职业复盘观察自己的表达模式与职业倾向。

当前版本：`2.0.0`（以 `SKILL.md` 中的版本声明为准）。

## 两种使用模式

| 模式 | 适合的情况 | 对话方式 | 最终产出 |
| --- | --- | --- | --- |
| A · 面试模式 | 已有目标岗位，希望练习面试 | 逐题提问、案例深挖、压力追问 | 百分制评分、优点与扣分点、优化动作清单 |
| B · 复盘模式 | 目标尚未明确，或希望了解自己的表达习惯 | 复述、确认、温和追问与原话回放 | 表达模式观察、能量清单、开放问题 |

两个模式拥有独立流程，启动时由你选择，不默认进入任何一种模式。

## 文件结构

```text
职业顾问/
├── README.md             # 使用说明（本文件，放入原目录后）
├── SKILL.md              # 角色、对话流程与输出规则
└── interview_record.md   # 个人经历、对话内容及进度记录
```

原始压缩包包含 `SKILL.md` 和一个空白的 `interview_record.md`。这是一个由 Markdown 文件组成的 Skill，不包含独立应用程序或安装脚本。

## 开始使用

1. 解压文件，将本 README 放入与 `SKILL.md` 相同的目录。
2. 在支持加载 `SKILL.md` 的 AI 助手中，按该工具的 Skill 加载方式导入目录。具体安装位置和调用方式以宿主工具的说明为准。
3. 启动 Skill，并选择 **A 面试模式** 或 **B 复盘模式**。
4. 按提示补充信息，开始对话。

如果使用普通聊天工具，也可以将 `SKILL.md` 作为对话参考材料提供，并明确要求按其流程开始。此方式下，历史记录的读取与保存需要手动处理，或由具备文件读写能力的工具完成。

### A · 面试模式示例

```text
选择 A 面试模式。
目标岗位：产品经理
期望行业：企业服务
求职阶段：社招

以下是目标岗位的 JD：
（粘贴职位描述）

以下是我的简历或相关经历：
（粘贴简历或经历）
```

有 JD 时，先提炼岗位要求并与你确认，再围绕技能、职责和业务场景出题；同时提供简历时，会结合岗位匹配情况追问。

没有 JD 也可以开始：提供岗位名称，使用预置岗位维度；若岗位未被覆盖，则补充该岗位的三个核心考核点。

### B · 复盘模式示例

```text
选择 B 复盘模式。
我还没确定下一步的职业方向，想从最近一次工作经历聊起。
```

不需要先准备目标岗位或 JD，可以从一件让你感到别扭、不甘心或印象深刻的工作事件开始。

## 功能说明

### A · 面试训练

- 每轮只提出一个问题，围绕具体回答持续追问。
- 对“执行力强”“有责任心”等描述，要求提供实际案例。
- 每三个常规问题插入一次压力追问。
- 回答困难时，将大问题拆成更小的问题，帮助回忆细节。
- 有多段经历时，优先选择与 JD 匹配、证据充分的经历。

预置岗位方向包括技术、产品、运营、销售、服务／客服、职能／行政、设计、市场／品牌、一线操作和海外涉外岗位，也支持自定义考核维度。

结束后，输出百分制得分、三个基于实际回答的核心优点、三个主要扣分点、可执行的优化动作，以及经历覆盖与 JD 对齐情况。

### B · 职业复盘

- 一次只问一个开放问题，通过复述、确认和进一步探索展开对话。
- 不打分、不施压，不直接给出“你应该怎样”的建议。
- 观察反复出现的用词、回避的话题和固定叙事方式。
- 在对话中段和结束时回放你的原话，邀请你自己理解这些表达之间的关系。

结束后，输出三个有原话依据的模式观察、一份反映话题表达活跃程度的能量清单，以及三个留待继续思考的开放问题。

### 模式衔接

B 模式结束后，如果目标逐渐明确，可以选择进入 A 模式练习对应岗位；A 模式结束后，也可以进入 B 模式，继续探索自己的回答方式。切换由你确认，不要求按固定顺序使用。

## 历史记录与个人复用

`SKILL.md` 约定将对话内容与个人经历写入同目录的 `interview_record.md`，使用 `[A]`、`[B]` 标注来源，并在下次启动时读取记录、承接进度。

**这些是 Skill 的行为约定，不是 Markdown 文件本身能够执行的功能。** 自动读写需要宿主工具具备相应能力和目录访问权限；仅上传文件或粘贴提示词时，不保证可以自动保存或跨会话读取。使用前应确认记录是否实际写入文件。

分享给他人时，建议复制一份目录，并清空副本中的 `interview_record.md`，避免带入自己的经历和对话内容。`SKILL.md` 无需为每位使用者单独修改。

## 使用建议

- 面试模式尽量提供完整 JD，以及包含职责、行动和结果的真实经历。
- 复盘模式可以从具体事件开始，不必预先组织成标准答案。
- 简历和记录可能包含个人或公司信息，提供材料前请删除不必要的敏感内容。
- 模拟评分与模式观察用于求职练习和自我反思，不能保证真实面试结果，也不等同于正式职业测评。
